# Discord Ticket Bot

A Discord bot for managing support tickets from inside a server. It's the Discord version of my [Java ticket queue system](https://github.com/zvoarch/Ticket-System), rebuilt with Node.js and the Discord API.

## Features

- Create support tickets with slash commands
- View a specific ticket
- View all available (open) tickets
- View solved tickets
- Object-oriented design with custom `Ticket` and `TicketQueue` classes
- Ticket history that separates active from resolved requests
